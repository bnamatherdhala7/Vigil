# Archive — Historical Working Documents

These documents were used during the project's interview / discovery phase and are preserved here for reference. They are **not** part of the active product documentation — they refer to specific people, conversations, and short-term framings that were useful at the time but should not be the public-facing artifacts.

For the active product narrative, see **[`docs/prd.md`](../prd.md)**.

| File | What It Is |

## Why these are archived, not deleted

Several of these documents contain useful frames that may be worth revisiting — the per-team customization examples, the product-decision rationale, the question-asking framework. Keeping them under `archive/` preserves the work without polluting the top-level documentation surface.
